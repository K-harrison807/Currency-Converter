# Exchange Rate Calculator
2. Description
   
A simple web-based currency converter built in my first year of study. 
It allows users to enter an amount in South African Rand (ZAR) and 
see the equivalent value in multiple currencies using fixed exchange rates.

4. Features
Input amount in ZAR

Conversion to multiple currencies (USD, EUR, GBP, JPY, AUD, CAD, CHF, CNY, INR, BRL)

Simple HTML, CSS, and JavaScript implementation

Table display of results

4. How to Run

1. Clone the repository
2. Open currencyConverter.html in your browser

Exchange rates are hardcoded and not live.

This was a first-year learning project, so it’s intentionally simple.

Future improvement: integrate with a real API for live rates.
